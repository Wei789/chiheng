# 待補資料清單（【待老闆提供：…】）

以下佔位文字需由網站負責人提供真實資料後替換。**請勿隨意填寫虛構資料**；若某項不適用（例如沒有相關證照），請直接刪除該段落。

| 佔位文字 | 檔案 | 說明 |
|---|---|---|
| 【待老闆提供：聯絡信箱】 | `contact/index.html` | 對外聯絡用的 Email（建議用網域信箱，例如 Cloudflare Email Routing 轉寄）。可改成 `<a href="mailto:...">` 連結。 |
| 【待老闆提供：營運者姓名或團隊名稱】 | `about/index.html` | 網站營運者名稱（個人姓名、筆名或團隊名皆可）。 |
| 【待老闆提供：營運者簡介】 | `about/index.html` | 一兩句介紹：為什麼做這個網站、背景。 |
| 【待老闆提供：相關專業背景或證照（若無可刪除此段）】 | `about/index.html` | 真實的相關經歷或證照；沒有就刪除整段 `<p>`。 |
| 【待老闆提供：所在地（國家／城市）】 | `about/index.html` | 例如「台灣・台北」。 |

## 檢查是否已全部替換

```
grep -rn "待老闆提供" --include=*.html .
```

沒有輸出即代表全部完成。
